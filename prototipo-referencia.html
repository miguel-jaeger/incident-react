api

Endpoints UTP incident-controller

Host: https://api-incident.onrender.com | OpenAPI Specification 3.0

GET /api/incidents
200 OK Array

Obtiene el listado completo de incidencias reportadas en sedes UTP.

POST /api/incidents
201 Created

Crea un nuevo ticket asignando título, descripción, prioridad y estado inicial.

{
  "title": "Falla Switch Core Pabellón C",
  "description": "Pérdida de conectividad intermitente",
  "priority": "High",
  "status": "Active"
}
PATCH /api/incidents/{id}/status
200 OK

Alterna o actualiza el estado (Active / Inactive) e incluye motivo de resolución o rechazo.

GET /api/incidents/{id}
200 OK Incident

Obtiene el objeto detallado del incidente por su identificador numérico.

DELETE /api/incidents/{id}
204 No Content

Elimina permanentemente el registro del servidor central.
